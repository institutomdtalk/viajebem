# Viaje Bem — site único do curso

Endereço final (depois de publicado): https://institutomdtalk.github.io/viajebem/

## Estrutura (ordem do curso)
- `index.html` — Boas-Vindas (página inicial; os cartões do mapa levam a cada módulo)
- `01-primeiras-impressoes/` · `02-aeroporto/` · `03-hospedagem/` · `04-locomocao/`
- `05-restaurantes/` · `06-compras/` · `07-farmacia/`
- `bonus-vinhos/` (Wine English) · `bonus-final/` (The Confident Traveler)

Cada pasta tem a página (`index.html`) e o PDF do módulo. No fim de cada página há o botão
"Baixar o material em PDF" e a navegação "Anterior / Todos os módulos / Próximo".
No fim de cada PDF há um QR code que abre a página do módulo.

## Como publicar
1. No GitHub da institutomdtalk, crie um repositório chamado `viajebem` (público).
2. Envie todo o conteúdo da pasta `viajebem` (o `index.html`, os PDFs e as pastas), mantendo a estrutura.
3. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.

## Links antigos
Na pasta `redirecionamentos` há um `index.html` para cada repositório antigo
(viajebem0 a viajebem8, viajebembonus e vinum). Substitua o `index.html` de cada
repositório antigo pelo arquivo correspondente.
